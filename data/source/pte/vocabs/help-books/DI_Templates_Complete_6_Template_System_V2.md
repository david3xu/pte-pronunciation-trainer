## 🔥 TEMPLATE A: Single Category Data Charts (30.4% - HIGHEST PRIORITY)

**Use for:** Bar charts, Pie charts, Line graphs, Tables with ONE variable

### COMPLETE TEMPLATE (90 words, 38-40 seconds)

```
This [chart type] | ILLUSTRATES information | REGARDING [title].

At the TOP, | [largest item] | DEMONSTRATES the HIGHEST value, | 
which is approximately [max value with unit].

Following THAT, | [second item] | SHOWS around [second value with unit], | 
representing the SECOND-highest figure.

Conversely, | [smallest item] | INDICATES the LOWEST value | 
at approximately [min value with unit].

Additionally, | [other item 1] | and [other item 2] | 
also contribute SIGNIFICANTLY | to the data ANALYSIS.

In CONCLUSION, | this chart PRESENTS comprehensive DATA | 
demonstrating CLEAR variations | in [topic].
```

### HOW TO FILL IN:
- **[chart type]** = "bar chart", "pie chart", "line graph", "table"
- **[title]** = Main topic from the chart title
- **[largest item]** = Category with highest value
- **[max value with unit]** = Number + unit (e.g., "72 percent", "350 million dirhams")
- **[second item]** = Category with second-highest value
- **[second value]** = Its value
- **[smallest item]** = Category with lowest value
- **[min value]** = Its value
- **[other item 1] and [other item 2]** = Any other 2 visible categories
- **[topic]** = Restate the main topic

### EXAMPLES FROM 92 IMAGES:
✅ Years to Double Population (#031001)
✅ Dubai Gold Sales in 2002 (#031002)
✅ Jill's Secondary Math Scores (#031007)
✅ Number of Laws in Brazil (#031014)
✅ Australian Age Group (#031053)
✅ Pet Expenditure in US (#031133)

### PRONUNCIATION GUIDE:
- **"|"** = Pause 0.3-0.5 seconds (breathe here)
- **CAPITALS** = Stress these words (louder/clearer)
- **Numbers:** Always stress FIRST part: "SEVENTY-two", "THREE hundred"
- **"DEMONSTRATES"** = "DEM-on-STRATES" (4 syllables, stress first)
- **"approximately"** = "ap-PROX-i-mate-ly" (5 syllables, stress second)

at approximately [cat2 max value].

Furthermore, | [any item 1] | and [any item 2] |

- **[cat1 max value]** = Its value
- **[cat1 min item]** = Item with lowest value in category 1
- **[cat1 min value]** = Its value
- **[cat2 max item]** = Item with highest value in category 2
- **[cat2 max value]** = Its value
- **[any item 1] and [any item 2]** = Any other items across both categories

## 🟠 TEMPLATE F: Diagrams / Illustrations (17.4% - HIGH PRIORITY)

**Use for:** Food pyramids, Cross-sections, Layered diagrams, Educational infographics, Scientific illustrations

### COMPLETE TEMPLATE (90 words, 36-38 seconds)

```
This DIAGRAM | ILLUSTRATES information about | [topic/concept].

The STRUCTURE is organized into | [number] MAIN sections or layers.

At the TOP, | [section 1] | is POSITIONED, | 
representing [what it shows].

In the MIDDLE portion, | [section 2] and [section 3] | 
are DISPLAYED, | indicating [what they represent].

At the BASE or BOTTOM, | [section 4] | APPEARS, | 
showing [what it represents].

Additionally, | VARIOUS labels and VISUAL elements | 
provide DETAILED information about | [specific aspects].

In CONCLUSION, | this diagram EFFECTIVELY explains | 
the STRUCTURE and COMPONENTS | of [topic].
```

### HOW TO FILL IN:
- **[topic/concept]** = What the diagram explains (e.g., "nutritional guidelines", "earth's structure")
- **[number]** = How many main sections/layers (e.g., "five", "three")
- **[section 1]** = What's at the top (e.g., "junk food", "the atmosphere")
- **[what it shows]** = What that section represents (e.g., "foods to consume sparingly", "gaseous layer")
- **[section 2] and [section 3]** = Middle sections
- **[what they represent]** = What they show
- **[section 4]** = Bottom section
- **[what it represents]** = What it shows
- **[specific aspects]** = Any details visible (e.g., "recommended daily servings", "temperature ranges")

## 🟡 TEMPLATE C: Flow Charts / Process Diagrams (10.9% - MEDIUM PRIORITY)

**Use for:** Sequential processes, Workflows, Manufacturing steps, Procedural diagrams, Cycles

### COMPLETE TEMPLATE (95 words, 38-40 seconds)

```
This FLOW chart | DEPICTS the PROCESS of | [title/topic].

INITIALLY, | the process COMMENCES with | [step 1], | 
which serves as the STARTING point.

SUBSEQUENTLY, | [step 2] | OCCURS as the NEXT stage, | 
involving [brief detail if visible].

Following THAT, | [step 3] | TAKES place, | 
which LEADS to [step 4].

In the FINAL stage, | [last step] | REPRESENTS the CONCLUSION | 
of this systematic PROCESS.

In SUMMARY, | these SEQUENTIAL steps | 
clearly DEMONSTRATE | how [title/topic] OPERATES effectively.
```

**FOR CYCLE DIAGRAMS (循环图):** Replace last sentence with:
```
In SUMMARY, | upon COMPLETION, | the process RETURNS | 
to the INITIAL stage, | creating a CONTINUOUS cycle.
```

### HOW TO FILL IN:
- **[title/topic]** = What process is shown (e.g., "water purification", "manufacturing")
- **[step 1]** = First step in the process
- **[step 2]** = Second step
- **[brief detail]** = Any small visible detail (optional, can skip if none)
- **[step 3]** = Third step
- **[step 4]** = Fourth step (if visible)
- **[last step]** = Final step in the process

**Use for:** Photographs, Real-world scenes, People, Buildings, Events, Illustrations of activities

### COMPLETE TEMPLATE (90 words, 36-38 seconds)

```
This PHOTOGRAPH | ILLUSTRATES information about | [general topic/scene].

In the FOREGROUND, | [main subject/person/object] | 
APPEARS as the PRIMARY focus, | showing [activity/characteristic].

Just ADJACENT to that, | [secondary element 1] and [secondary element 2] | 
provide ADDITIONAL context | to the SCENE.

In the BACKGROUND, | [describe setting/scenery] | 
CREATE the environmental SETTING, | featuring [details like colors/weather].

Additionally, | [other visible elements] | 
CONTRIBUTE to the OVERALL composition.

In CONCLUSION, | this image EFFECTIVELY captures | 
[overall message/theme/purpose].
```

### HOW TO FILL IN:
- **[general topic/scene]** = Overall subject (e.g., "a business meeting", "urban lifestyle", "shopping")
- **[main subject/person/object]** = Main focus (e.g., "a young woman", "a building", "people")
- **[activity/characteristic]** = What they're doing or key feature (e.g., "crossing the road", "presenting data")
- **[secondary element 1] and [secondary element 2]** = Things near the main subject (e.g., "cars and trees", "laptops and documents")
- **[describe setting/scenery]** = Background description (e.g., "modern office space", "city street")
- **[details like colors/weather]** = Visual details (e.g., "bright lighting", "cloudy sky")
- **[other visible elements]** = Anything else (e.g., "signage", "furniture")
- **[overall message/theme/purpose]** = What the image represents (e.g., "professional collaboration", "modern urban life")

## 📝 UNIVERSAL PRONUNCIATION RULES

### Numbers:
| Written | ❌ WRONG | ✅ CORRECT |
|---------|---------|-----------|
| 1700-1999 | "one seven zero zero" | "SEVENTEEN hundred", "NINETEEN ninety-five" |
| 2000-2009 | "two zero zero five" | "TWO thousand", "TWO thousand and FIVE" |
| 2010+ | "two zero one five" | "TWENTY ten", "TWENTY fifteen" |
| 72% | "seventy two percent" | "SEVENTY-two percent" (stress first part) |
| 3.5 million | "three five million" | "THREE point FIVE million" |
| 1,250 | "one two five zero" | "ONE thousand TWO hundred fifty" |

### Stress Patterns:
- **Numbers:** Always stress FIRST part: "SEVENTY-two", "THREE hundred"
- **Transitions:** "Following THAT", "SUBSEQUENTLY", "Additionally"
- **Data words:** "HIGHEST", "LOWEST", "DEMONSTRATES", "INDICATES"
- **Conclusions:** "In CONCLUSION", "OVERALL", "In SUMMARY"

### Pause Points ("|" marks):
- After introduction sentence = 0.5 seconds
- Between major data points = 0.3-0.5 seconds
- Before conclusion = 0.5 seconds
- At all "|" marks = 0.3-0.5 seconds (breathe naturally)
