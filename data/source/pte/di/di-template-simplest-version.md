# PTE Describe Image - SIMPLEST Template (Easiest to Speak)

## For Photos/General Images - Ultra Simple Version 🌟

### **Template Structure:**

```
This picture shows [topic].

We can see [point 1].

Also, [point 2].

Finally, [point 3].

Overall, this picture gives information about [topic].
```

---

## **Example: Kitchen Storefront**



### **What You Say:**

```
This picture shows a kitchen restaurant.

We can see, the word "kitchen" is written on the building.

Also, there are tables and chairs outside.

Finally, a person is sitting inside near the window.

Overall, this picture gives information about a street restaurant.
```

---

## **Why This Works:**

✅ **"We can see"** - Super easy to say, no "that" needed
✅ **"Also"** - One word, simple
✅ **"Finally"** - One word, natural ending
✅ **Short sentences** - Easy to remember
✅ **Simple words** - No complex vocabulary

---

## **SIMPLEST Linking Words (No "That" Version)**

| Point | Linking Word | Example |
|-------|--------------|---------|
| **Point 1** | **We can see** | We can see, the building is white |
| **Point 2** | **Also** | Also, there are outdoor seats |
| **Point 3** | **Finally** | Finally, glass windows show the inside |

---

## **Alternative Super Simple Links:**

### **Version 1** (Shortest)
1. **First** (Point 1)
2. **Next** (Point 2)
3. **Last** (Point 3)

**Example:**
```
First, the sign says kitchen.
Next, outdoor furniture is visible.
Last, one customer sits inside.
```

### **Version 2** (Natural)
1. **I can see** (Point 1)
2. **Also** (Point 2)
3. **And** (Point 3)

**Example:**
```
I can see, this is a kitchen restaurant.
Also, tables are placed outside.
And, someone is dining indoors.
```

## **For Data Charts - SIMPLEST Version**

### **Template:**

```
This [chart type] shows [topic].

First, [highest item] has [value].

Next, [second item] has [value].

Last, [lowest item] has [value].

Overall, this shows data about [topic].
```

### **Example: Bar Chart**

```
This bar chart shows student numbers.

First, China has 500 million students.

Next, USA has 300 million.

Last, UK has 100 million.

Overall, this shows data about education.
```

---

## **Key Rules for EASIEST Speaking:**

1. ✅ Use **short words**: First, Next, Last, Also, And
2. ✅ Avoid **"that"** if it confuses you
3. ✅ Keep sentences **short** (5-7 words per sentence)
4. ✅ Only **3 points** - don't add more
5. ✅ Use **commas** to pause naturally

## **Comparison: Complex vs. Simple**

| Style | Linking Phrase | Difficulty |
|-------|---------------|------------|
| **Complex** | "It is evident that" | Hard - 4 words + "that" |
| **Medium** | "We can see that" | Medium - 3 words + "that" |
| **SIMPLE** | "We can see" | ✅ Easy - 3 words, no "that" |
| **SIMPLEST** | "First" / "Next" | ✅✅ Easiest - 1 word! |
