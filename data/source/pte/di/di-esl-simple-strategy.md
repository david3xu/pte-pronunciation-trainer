# PTE Describe Image - Simple Strategy for ESL Learners

## The Problem:
- ❌ Too hard to think in English under pressure
- ❌ Can't create perfect sentences quickly
- ❌ Worried about what to say

## The Solution: JUST POINT AT 3 THINGS! 👉

---

## **Super Simple Rule:**

### **Step 1: See 3 things (ANY 3 things)**
Point at ANY 3 things you see in the image. Don't think too much!

### **Step 2: Use this pattern:**

```
[Intro]
First, [thing 1].
Also, [thing 2].
Finally, [thing 3].
[End]
```

---

## **Example: Kitchen Image**

### **What you SEE (in 25 seconds):**
1. 👉 Sign says "kitchen"
2. 👉 Tables outside
3. 👉 Person inside

### **What you SAY (simple):**

```
This picture shows a kitchen.

First, I can see the word kitchen on the building.

Also, there are some tables and chairs outside.

Finally, there is a person inside.

That's all.
```

**Time:** ~25 seconds
**Easy? YES!**

---

## **Even SIMPLER Version (for beginners):**

### **What you SEE:**
1. 👉 White building
2. 👉 Chairs
3. 👉 One person

### **What you SAY:**

```
This shows a restaurant.

First, white building.

Also, many chairs.

Finally, one person.

That's all.
```

**Time:** ~15 seconds (TOO SHORT!)

### **Add MORE WORDS:**

```
This picture shows a restaurant on the street.

First, I can see a white building with big windows.

Also, there are many chairs and tables on the street.

Finally, there is one person sitting inside the restaurant.

That's all about this picture.
```

**Time:** ~30 seconds ✅

---

## **The Magic Formula for 30 Seconds:**

### **Count your words!**

| Part | Words Needed | Example |
|------|-------------|---------|
| **Intro** | 6-8 words | "This picture shows a restaurant on the street" (8 words) |
| **First** | 10-12 words | "First, I can see a white building with big windows" (11 words) |
| **Also** | 10-12 words | "Also, there are many chairs and tables on the street" (11 words) |
| **Finally** | 10-12 words | "Finally, there is one person sitting inside the restaurant" (10 words) |
| **End** | 4-6 words | "That's all about this picture" (5 words) |

**Total:** 45-50 words = 30 seconds! ✅

---

## **How to Add More Words (Make Sentences Longer):**

### **Short sentence:**
"First, white building"

### **Add "I can see":**
"First, I can see a white building"

### **Add color/size:**
"First, I can see a large white building"

### **Add location/detail:**
"First, I can see a large white building with big windows"

✅ Now it's 11 words!

---

## **Simple Word Fillers (To Make 30 Seconds):**

Use these to make your sentences longer:

| Add This | Example |
|----------|---------|
| **I can see** | "I can see a white building" |
| **There is/are** | "There are many chairs" |
| **with** | "a building with windows" |
| **and** | "tables and chairs" |
| **on the street** | "chairs on the street" |
| **inside/outside** | "sitting inside the restaurant" |
| **big/small/many** | "many chairs, big windows" |
| **some** | "some tables outside" |

## **3 Ready-to-Use Patterns:**

### **Pattern 1** (Easiest - for ANY image)
```
This picture shows [topic].
First, I can see [thing 1].
Also, there is [thing 2].
Finally, [thing 3] is visible.
That's all about this picture.
```

### **Pattern 2** (Natural)
```
This image shows [topic].
First, [thing 1].
Also, I notice [thing 2].
Finally, we can see [thing 3].
Overall, this shows [topic].
```

### **Pattern 3** (Simple)
```
Looking at this picture, [topic].
First, there is [thing 1].
Also, [thing 2].
Finally, [thing 3].
That's all.
```

---

## **Practice Method:**

### **During 25 seconds preparation:**

1. **Write 3 things:**
   - Sign
   - Chairs
   - Person

2. **Add words:**
   - "kitchen" sign
   - tables and chairs outside
   - one person inside

3. **Count:** Need 45-50 words? Add "I can see", "there is/are"

4. **Speak!**

---

## **For Charts (Same Easy Method):**

### **Bar Chart Example:**

**What you SEE:**
1. 👉 China = highest
2. 👉 USA = middle
3. 👉 UK = lowest

**What you SAY:**

```
This chart shows student numbers in different countries.

First, I can see China has the highest number.

Also, USA has a medium number of students.

Finally, UK has the smallest number in this chart.

Overall, this shows education data.
```

**Time:** ~30 seconds ✅
