# AI/ML TERMS PRONUNCIATION PRACTICE - INTERVIEW FOCUSED

*Essential AI/ML terminology with pronunciation guides for technical interviews*

## Foundation Terms (Everyone Uses These)

**Artificial Intelligence** | /ˌɑː.tɪˈfɪʃ.əl ɪnˈtel.ɪ.dʒəns/ — sounds like **AHR-ti-FISH-ul in-TEL-i-juns** | /ˌɑr.təˈfɪʃ.əl ɪnˈtel.ə.dʒəns/ — sounds like **AHR-tuh-FISH-ul in-TEL-uh-juns**

Field enabling computers to perform tasks requiring human intelligence like learning, perception, and decision-making.

**Machine Learning** | /məˈʃiːn ˈlɜː.nɪŋ/ — sounds like **muh-SHEEN LUR-ning** | /məˈʃin ˈlɝ.nɪŋ/ — sounds like **muh-SHEEN LUR-ning**

Subset of AI where computers learn patterns from data without explicit programming.

**Deep Learning** | /diːp ˈlɜː.nɪŋ/ — sounds like **DEEP LUR-ning** | /dip ˈlɝ.nɪŋ/ — sounds like **DEEP LUR-ning**

Advanced ML using multi-layered neural networks to analyze complex data, inspired by human brain structure.

**Large Language Models** | /lɑːdʒ ˈlæŋ.ɡwɪdʒ ˈmɒd.əlz/ — sounds like **LAHRJ LANG-gwij MOD-ulz** | /lɑrdʒ ˈlæŋ.ɡwɪdʒ ˈmɑ.dəlz/ — sounds like **LAHRJ LANG-gwij MAH-duhlz**

AI models trained on vast text datasets to understand and generate human-like language (e.g., GPT, Claude, Gemini).

**Neural Networks** | /ˈnjʊə.rəl ˈnet.wɜːks/ — sounds like **NYOOR-ul NET-wurks** | /ˈnʊr.əl ˈnet.wɝks/ — sounds like **NOOR-ul NET-wurks**

Computing systems with interconnected nodes processing information, foundation of modern AI.

**Model** | /ˈmɒd.əl/ — sounds like **MOD-ul** | /ˈmɑ.dəl/ — sounds like **MAH-duhl**

Trained algorithm that makes predictions or generates outputs; the result of training on data.

**Training** | /ˈtreɪ.nɪŋ/ — sounds like **TRAY-ning** | /ˈtreɪ.nɪŋ/ — sounds like **TRAY-ning**

Process of teaching model by exposing it to data so it learns patterns.

**Inference** | /ˈɪn.fər.əns/ — sounds like **IN-fur-uns** | /ˈɪn.fɚ.əns/ — sounds like **IN-fur-uns**

When trained model makes predictions on new data it hasn't seen before.

**Parameters** | /pəˈræm.ɪ.təz/ — sounds like **puh-RAM-i-turz** | /pəˈræm.ə.tɚz/ — sounds like **puh-RAM-uh-turz**

Adjustable values in model that get tuned during training to improve performance (e.g., "7B parameters").

**Fine-Tuning** | /faɪn ˈtjuː.nɪŋ/ — sounds like **FYNE TOO-ning** | /faɪn ˈtu.nɪŋ/ — sounds like **FYNE TOO-ning**

Further training pre-trained model on specific dataset to specialize for particular task.

## Essential Production Terms

**Prompt Engineering** | /prɒmpt ˌen.dʒɪˈnɪə.rɪŋ/ — sounds like **PROMPT en-ji-NEER-ing** | /prɑmpt ˌen.dʒəˈnɪr.ɪŋ/ — sounds like **PRAHMPT en-juh-NEER-ing**

**Prompt** | /prɒmpt/ — sounds like **PROMPT** | /prɑmpt/ — sounds like **PRAHMPT**

**Token** | /ˈtəʊ.kən/ — sounds like **TOH-kun** | /ˈtoʊ.kən/ — sounds like **TOH-kun**

Smallest unit of text model processes; models have token limits.

**Hallucination** | /həˌluː.sɪˈneɪ.ʃən/ — sounds like **huh-LOO-si-NAY-shun** | /həˌlu.səˈneɪ.ʃən/ — sounds like **huh-LOO-suh-NAY-shun**

When AI generates false or fabricated information confidently.

**Retrieval-Augmented Generation** | /rɪˈtriː.vəl ɔːɡˈmen.tɪd ˌdʒen.ərˈeɪ.ʃən/ — sounds like **ri-TREE-vul awg-MEN-tid jen-ur-AY-shun** | /rɪˈtri.vəl ɔrɡˈmen.təd ˌdʒen.ɚˈeɪ.ʃən/ — sounds like **ri-TREE-vul awrg-MEN-tud jen-ur-AY-shun**

**Vector Database** | /ˈvek.tər ˈdeɪ.tə.beɪs/ — sounds like **VEK-tur DAY-tuh-bays** | /ˈvek.tɚ ˈdeɪ.tə.beɪs/ — sounds like **VEK-tur DAY-tuh-bays**

**API** | /eɪ piː aɪ/ — sounds like **AY PEE EYE** | /eɪ pi aɪ/ — sounds like **AY PEE EYE**

**Endpoint** | /ˈend.pɔɪnt/ — sounds like **END-poynt** | /ˈend.pɔɪnt/ — sounds like **END-poynt**

**Test Data** | /test ˈdeɪ.tə/ — sounds like **TEST DAY-tuh** | /test ˈdeɪ.tə/ — sounds like **TEST DAY-tuh**

**Reinforcement Learning** | /ˌriː.ɪnˈfɔːs.mənt ˈlɜː.nɪŋ/ — sounds like **ree-in-FAWRSS-munt LUR-ning** | /ˌri.ɪnˈfɔrs.mənt ˈlɝ.nɪŋ/ — sounds like **ree-in-FAWRSS-munt LUR-ning**

**Overfitting** | /ˌəʊ.vərˈfɪt.ɪŋ/ — sounds like **OH-vur-FIT-ing** | /ˌoʊ.vɚˈfɪt.ɪŋ/ — sounds like **OH-vur-FIT-ing**

**Data Drift** | /ˈdeɪ.tə drɪft/ — sounds like **DAY-tuh DRIFT** | /ˈdeɪ.tə drɪft/ — sounds like **DAY-tuh DRIFT**

**Hyperparameter** | /ˌhaɪ.pərˈpær.ə.mɪ.tər/ — sounds like **hy-pur-PAR-uh-mi-tur** | /ˌhaɪ.pɚˈpær.ə.mə.tɚ/ — sounds like **hy-pur-PAR-uh-muh-tur**
